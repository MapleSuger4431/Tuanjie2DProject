# Layout Intent Validation

## Error：阻止确认

- 项目、画布列表、画布或区域列表不存在。
- gameId 为空。
- activeCanvasId 未指向项目中的画布。
- 画布 ID 为空或重复。
- 画布 uiViewId 为空或重复。
- 画布宽高不大于 0。
- 区域为空、ID 为空或 ID 重复。
- 区域名称为空。
- 区域宽高小于 20×20。
- 区域超出画布。
- parentId 不存在、引用自己或形成循环。
- 区域嵌套深度超过 64 层。
- 子区域未完整包含在其父区域内（子区域 `rect` 使用画布全局坐标，校验时比较子区域与父区域的全局 `rect` 是否构成包含关系）。

## Warning：允许确认

- componentType 为空。
- `Label`、`Image`、`TextField`、`ListView`、`Slider`、`ProgressBar` 或 `Toggle` 等叶子型组件包含子区域。
- HUD 使用覆盖画布 90% 以上的 background 区域。

## 持久化语义

1. 开始确认前运行校验。
2. 有 Error 时保持 `isConfirmed=false`。
3. 无 Error 时进入保存或上传。
4. 保存/上传成功后，落盘 JSON 保持 `isConfirmed=true`。
5. 保存/上传失败时恢复 `isConfirmed=false`。
6. 确认后的任何数据修改都必须重置 `isConfirmed=false`。

## 画板层级交互

- 父级移动或缩放时同步变换全部后代。
- 子级直接移动或缩放时限制在父级矩形内。
- 树中拖到节点中部成为子级，拖到上下边缘调整同级顺序，拖到根级空白区域清空父级；禁止拖入自身或后代。
- 改变父级时保持子树尺寸，仅做进入新父级所需的最小平移；子树大于目标父级时拒绝。
- 删除或复制父级均作用于整棵子树；撤销恢复全部对象、父级、几何和原顺序。
- 父级隐藏使后代有效隐藏，父级锁定使后代有效锁定，但不覆盖后代自己的 `visible` / `locked` 值。
- 未锁定父级变换时仍带动本地锁定的后代；有效锁定的区域不能被直接移动、缩放、重排或删除。
- 层级编辑后按父节点优先的深度优先顺序规范化数组，保持每棵子树连续和同级顺序稳定。
- 新框选区域始终创建为根级；不按几何包含关系自动推断父级。
- 运行时确认校验必须检查子级包含关系，不能只依赖画板交互。

调用方不依赖运行时事件或状态查询 API。用户告知确认后，以
`context/games/{GameName}/LayoutIntent/layout_intent.json`
是否存在、其中 `isConfirmed` 是否为 `true`、且 `canvases` 是否包含全部目标界面作为完成判据。
