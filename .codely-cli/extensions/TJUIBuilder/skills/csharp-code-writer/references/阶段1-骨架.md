# 阶段 1 · 骨架先落盘（进入本阶段时才读本文件）

> **本阶段唯一目标：用最小思考量，把每个脚本的"空壳"写进 `context/games/{GameName}/GameScripts/*.cs`。**
> 方法体一律先留 `// TODO`，逻辑推演全部推迟到阶段 2。骨架先落盘 = 自带 checkpoint，即便后面某个方法单独超时，已落盘的骨架不报废。

---

## 🔒 本阶段的硬顺序（不可绕过，违反=本次任务失败模式）

实测：写 C# 的 301s 超时几乎都死在"写下第一行代码之前"——模型在骨架落盘前反复 `grep` API 参考文档、`read` 框架源码，把请求时间耗光。所以本阶段用物理顺序阻断它：

```
读架构文档对应小节  →  write_file 落骨架  →  (阶段1到此结束)
```

- ⛔ **骨架落盘前，禁止 `read_file` / `grep` 任何 `.cs` 源码**（框架源码、别的脚本一律不读）。查签名、填方法体是**阶段 2** 的事，骨架阶段根本不需要。
- ⛔ 连续 3~4 轮只 `read_file`/`glob` 而没有 `write_file` = 过度准备，立即写骨架。
- ✅ 本阶段允许读的，只有下面「契约 pass」列的**架构文档小节**（自然语言契约，不是代码）。
- 🔁 骨架 `write_file` 明确失败/超时时，立即读回目标：已有完整骨架则继续；没有则将字段/方法签名拆成 ≤60 行重试，仍失败再读回后以 ≤30 行续写。两次恢复前禁止退出 task。

## 一、契约 pass（动笔前只做一次，只读架构文档，不读实现）

🔴 首选读 `context/games/{GameName}/代码架构文档.md`——它是跨脚本契约的**单一真相源**，照它写、不现场权衡选件。**按标题/语义定位，不依赖固定章节号**：

- **概述与 Job Plan 输入摘要**（旧 §1）：逐字采用唯一根命名空间。
- **共享类型注册表**（旧 §2）：确认唯一定义文件。
- **脚本清单与业务契约**（旧"脚本清单"）：搬运本脚本的业务公共接口、依赖、精确基类和必要业务引用。这里只创建业务 API 空壳。
- **事件契约**（旧"事件流向表"）：确认本脚本发布/订阅哪一端；自定义事件载荷以注册表/事件表为准。
- **UI 数据唯一产出**（旧"核心数值产出端归属"）：确认本脚本是否为某 HUD/面板数据的唯一产出方（如计分显示的绑定来源）。
- **ScriptableObject 配置**（旧 SO 配置章）：仅配置脚本需要。

> 无架构文档时回退：UI需求/设计文档的挂载与交互约定就是最小脚本合同，读取其精确基类/接口、业务公共接口与必要引用；task prompt 只补充当前脚本组边界，不得把"无独立架构文档"当作允许现场设计。
> 分批写脚本时，引用共享类型前先按注册表归属 + `grep` GameScripts 确认（见检查清单 G 节）——这是**唯一**允许在骨架前 grep 的例外，且只 grep 类名存在性，不读实现。

## 二、下笔前只定这 4 件事（唯一的"起草前"清单）

1. **这脚本还用不用写（UI 框架件选型）**：本阶段不现场扫描任何 API 文档；直接采用"脚本清单与业务契约"记录的精确基类和业务边界。UI 框架已有件优先复用：UI 启动入口 → `MonoBehaviour`（UIGameInstaller，调 `UIFrame.InitializeUGUI`/`UIFrame.Initialize`）、面板 → `UGUIPanelBase`/`UIPanelBase`、HUD 面板 → `UGUIGameControllerBase`/`GameUIControllerBase`（自带状态订阅与每帧刷新）、UI 状态驱动 → `UIFrame.SetGameState(string)` / 订阅 `UIFrame.StateChanged`、游戏数据 → `UIFrame.DI` 注册的业务服务（如 `IGameService`）、UI 点击音效 → `UIAudioFeedback`（UGUI 组件直挂）或游戏侧服务。签名和钩子留到阶段 2 按 `UIFrame-API.md` 核对。
2. **HUD 数据的"果"有没有产出端**：每个 HUD 显示值必有**一行代码产出它**（绑定属性赋值 / 游戏服务调用 `UIFrame.SetGameState`）。产出端归属优先见架构文档"UI 数据唯一产出"；本脚本不是指定产出方时只订阅/读取、**不得再产出**。
3. **基类选择**：面板类脚本必须继承对应 Panel 基类并加 `[Panel("注册名", gameId: "{GameName}")]` 特性；HUD 常驻面板用 `UGUIGameControllerBase`/`GameUIControllerBase`；纯胶水脚本用普通 MonoBehaviour。
4. **引用方式**：场景/Prefab 引用一律 `[SerializeField] private` + Inspector 接线（UIGameInstaller 的 canvas/panelRegistry 等）；**初始面板名禁止 `[SerializeField] private string`**（场景旧序列化值会覆盖代码默认值），用 `PanelNames` 常量类。

> 其余一切检查类规则（占位返回、事件退订、绑定空引用、UI 遮挡……）**都不在骨架阶段对表**——它们在阶段 3 被 RoslynValidator / 编译 / Play 冒烟抓出并修补。骨架阶段预演这些 = 违反本技能。
