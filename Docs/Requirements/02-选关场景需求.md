# 02 · 选关场景需求

> 玩家在主菜单与游戏关卡之间的枢纽：浏览章节与关卡、查看进度与星级、进入已解锁关卡。
> 基线设定见 [README](README.md)。优先级：P0 必须 / P1 重要 / P2 可选。

## 1. 范围

- 选关场景（`LevelSelect`）的界面、数据结构展示与交互流程。
- 关卡解锁规则的对外行为（规则本身由存档系统落地存储，见 05 篇）。
- **不包含**：关卡内部玩法（见 03 篇）、关卡内容设计（属关卡配置表，程序只消费数据）。

## 2. 进入与出口

- **进入**：主菜单「选关」/「继续游戏」；游戏结算界面「返回选关」。
- **出口**：点击关卡 → `Game` 场景；「返回」按钮 → 主菜单场景。
- 从「继续游戏」进入时，自动定位（滚动）到最新解锁的关卡处。

## 3. 数据组织

- 关卡按 **章节（Chapter）→ 关卡（Level）** 两级组织，配置于关卡配置表（ScriptableObject）。
- 每关对玩家暴露的字段：所属章节、关卡编号、关卡名称、解锁状态、历史最高星级（0–3）。
- 每关的解锁规则（P0 基线）：**通关第 N 关解锁第 N+1 关**；每章第 1 关默认锁定，通关上一章最后一关后解锁；第 1 章第 1 关初始即解锁。

## 4. 界面元素

- 顶部：场景标题、返回按钮、进度总览（总星数 x/y）
- 主体：章节分区 + 关卡按钮网格（每关一格）
- 关卡按钮内容：编号、名称（可选）、锁定图标 / 星级（0–3 星）
- （P2）选中关卡后的详情浮层：目标简述、历史最佳步数

## 5. 功能需求

### LS-01 章节-关卡两级展示（P0）
- **需求**：按章节分组展示全部关卡，章节有标题；单章关卡超过一屏时可滚动。
- **验收**：配置表中有 N 章 M 关时，界面完整呈现 N 个章节分区与 M 个关卡按钮，无遗漏无错位。

### LS-02 关卡三态显示（P0）
- **需求**：每关按钮呈现三种视觉状态之一——**锁定**（锁图标、置灰、不显示星级）、**已解锁未通关**（正常态、无星）、**已通关**（正常态 + 历史最高星级 1–3 星）。
- **验收**：按存档数据正确渲染三态；通关一关后返回，该关由"无星"变为对应星级，下一关由"锁定"变为"已解锁"。

### LS-03 解锁规则生效（P0）
- **需求**：严格按第 3 节的解锁规则判定每关可否进入；不允许跳关（包括编辑器外的任何入口）。
- **验收**：新存档只能进入第 1 章第 1 关；通关第 N 关后第 N+1 关可进入；通过直接指定关卡 ID 的方式进入未解锁关时应被拒绝并返回选关。

### LS-04 星级展示（P0）
- **需求**：已通关关卡显示历史最高星级（取历次通关的最高值，不回退）。
- **验收**：同一关先 1 星通关再 3 星通关，显示 3 星；再 2 星通关，仍显示 3 星。

### LS-05 进入关卡（P0）
- **需求**：点击已解锁关卡，切换到 `Game` 场景并加载对应关卡配置。
- **验收**：点击后游戏场景中棋盘布局、目标、步数限制与配置表中该关数据一致。

### LS-06 锁定关卡的点击反馈（P1）
- **需求**：点击锁定关卡时不进入，给出反馈：按钮抖动动画 + 提示文案（"通关前一关后解锁"），或仅音效+抖动（文案可选）。
- **验收**：点击锁定关不发生场景切换，有可见反馈；无报错。

### LS-07 滚动与定位（P1）
- **需求**：关卡列表支持垂直滚动；从「继续游戏」或结算界面进入时，自动滚动到最新解锁关卡并使其位于可视区域中部。
- **验收**：长列表可顺畅滚动；自动定位后目标关卡在屏幕内且可见。

### LS-08 进度总览（P1）
- **需求**：界面顶部显示总进度：已获星数 / 总星数（如 12/45，总星数 = 关卡数 × 3），可选加显示已通关数。
- **验收**：数字与存档实际数据一致；通关任一关后返回，数字即时更新。

### LS-09 关卡详情预览（P2）
- **需求**：点击（或长按）关卡按钮先弹出详情浮层：关卡名称、目标简述、历史最佳步数/最高星级、『开始』按钮；再次点击或点空白处关闭。
- **验收**：浮层信息与配置表及存档一致；不实现本项时 LS-05 的直接进入行为不受影响。

### LS-10 返回主菜单（P0）
- **需求**：左上角返回按钮回到主菜单场景；移动端支持系统返回键等效操作。
- **验收**：点击返回后主菜单正常显示；Android 返回键行为一致。

## 6. 非功能需求

- 选关场景加载时间 ≤ 2 秒（PC），滚动帧率 ≥ 60 FPS（关卡按钮总数 ≤ 200 时）。
- 关卡按钮为可复用预制体，由配置驱动生成，新增关卡不改代码。

## 7. 边界与异常

| 情况 | 期望行为 |
|---|---|
| 无存档 | 第 1 章第 1 关解锁，其余锁定，总进度 0 |
| 存档损坏 | 按无存档处理（见 05 篇 SV-03） |
| 全部关卡通关 | 进度总览显示满进度，最新解锁定位到最后一关；可选显示"已全部通关"标记 |
| 配置表为空/缺章节 | 界面显示空态提示（"敬请期待"），不报错 |

## 8. 依赖

- 关卡配置表（ScriptableObject：章节、关卡、目标、步数限制、星级阈值）——本系统只读。
- 存档系统：读取/写入解锁进度与星级（05 篇 SV-01）。
- SceneModule：场景切换；UIModule：按钮与浮层。
