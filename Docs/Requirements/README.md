## 全局基线设定（各篇共用，评审时可调整）

- **游戏类型**：2D 棋盘解谜。**玩法方案存在两套互斥候选，待定稿**（见上表）：
  - 方案 A（03 篇，暂停）：8×8 国际象棋变体，固定关卡制、回合制走棋，无随机生成。
  - 方案 B（06 篇，当前推进）：15×15 棋盘，俄罗斯方块式随机块铺路 + AI 自动寻路，含格子随机属性与特殊效果。
- **美术风格**：参照 `Docs/ArtReference-2DChess/` 的调研结论（颜色即信息、棋盘退后焦点前冲、一套语法统一风格）。具体风格选定见各篇待定项。
- **目标平台**：PC（Windows/macOS）+ Android。输入需同时适配鼠标与触屏。
- **引擎与框架**：团结引擎 1.10.4；架构用 AesirFramework（RAA 架构 + RAM 模块：UI / Scene / Audio / Events）。
- **UI 文字**：TextMeshPro + NotoSansSC 中文字体（已接入，见 `Assets/Codely/`）。
- **输入**：仅用 Input System（Player Settings 已配置），鼠标点击 / 触屏点按为主操作。
- **场景规划（基线，待确认）**：

  | 场景 | 职责 | 备注 |
  |---|---|---|
  | `Bootstrap` | 启动初始化（已有，Build Settings index 0） | 只含 GameBootstrap + AudioListener |
  | `MainMenu` | 主菜单 | 设置、成就以 Panel/Window 叠加显示 |
  | `LevelSelect` | 选关 | 从主菜单进入 |
  | `Game` | 游戏运行 | 单一场景，按关卡配置数据动态生成棋盘 |

- **存档**：本地单存档槽，JSON 文件（详见 05 篇）。
