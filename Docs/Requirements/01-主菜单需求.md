# 01 · 主菜单需求

> 玩家启动游戏后看到的第一个交互界面，承担「进游戏、选关、看成就、调设置、退出」五个出口。
> 基线设定见 [README](README.md)。本文档优先级定义：P0 必须 / P1 重要 / P2 可选。

## 1. 范围

- 主菜单场景（`MainMenu`）中的全部 UI 与交互。
- 从主菜单叠加打开的设置面板（内容最小集在本篇定义）。
- **不包含**：成就列表界面内部逻辑（见 04 篇）、选关界面（见 02 篇）、存档读写实现（见 05 篇）。

## 2. 进入与出口

- **进入**：`Bootstrap` 场景初始化完成后，由 `GameBootstrap` 切换到主菜单场景并显示主菜单面板。
- **出口**：继续游戏 / 开始新游戏 / 选关 → `LevelSelect` 场景；成就、设置 → 当前场景叠加面板；退出 → 关闭应用。

## 3. 界面元素

- 游戏标题 Logo（占位文本即可，美术未定）
- 按钮组：继续游戏、开始新游戏、选关、成就、设置、退出
- 版本号（画面角落，格式 `v主.次.修订`）
- 背景与 BGM（占位资源）

## 4. 功能需求

### MM-01 标题与版本号显示（P0）
- **需求**：主菜单显示游戏标题（未定名，先用占位文本）与版本号；版本号取自 `Application.version`，不手填。
- **验收**：主菜单可见标题与版本号；版本号与 Player Settings 中的 Version 一致。

### MM-02 继续游戏（P0）
- **需求**：读取存档，若存在有效进度则按钮可用，点击进入 `LevelSelect` 场景并定位到最新解锁的关卡；无存档时按钮置灰不可点（或隐藏，二选一，默认置灰）。
- **验收**：①全新安装（无存档文件）时按钮置灰，点击无响应；②通关任意一关后返回主菜单，按钮可用，点击后进入选关且最新解锁关可见。

### MM-03 开始新游戏（P0）
- **需求**：无存档时直接进入第 1 关（`Game` 场景加载第 1 关配置）；已有存档时弹出二次确认（"开始新游戏将覆盖当前进度"），确认后重置存档并进入第 1 关，取消则关闭弹窗。
- **验收**：①无存档时点"开始新游戏"直接进入第 1 关；②有存档时必出现确认弹窗，点取消进度不变，点确认后存档重置、从第 1 关开始。

### MM-04 选关入口（P0）
- **需求**：点击切换到 `LevelSelect` 场景。
- **验收**：点击后选关场景正确加载，返回按钮可回到主菜单。

### MM-05 成就入口（P0）
- **需求**：点击打开成就列表界面（叠加面板，不切换场景），关闭后回到主菜单。
- **验收**：成就面板正常打开/关闭；列表内容与存档中的解锁状态一致（详见 04 篇）。

### MM-06 设置入口与设置面板（P1）
- **需求**：点击打开设置面板（叠加显示）。最小集只含两项：音乐音量、音效音量（各一条 0–100 滑条，实时生效）；其余设置项见待定项。
- **验收**：①拖动滑条时对应音量实时变化（音乐可立即在菜单 BGM 上听出）；②音量值写入存档，重进游戏后保持。

### MM-07 退出游戏（P0）
- **需求**：PC 平台点击后退出应用；Android 平台点击后弹出确认（"确定退出？"）再退出；编辑器内点击等效于停止播放。
- **验收**：三端行为分别符合描述；退出前触发一次存档写入兜底（见 05 篇 SV-02）。

### MM-08 主菜单 BGM（P1）
- **需求**：进入主菜单场景时播放菜单 BGM（循环）；切换到选关/游戏场景时按各场景要求停止或切换。
- **验收**：主菜单可听到循环 BGM，音量受设置面板音乐滑条控制；场景切换后无音乐重叠播放。

### MM-09 按钮交互反馈（P1）
- **需求**：所有可点按钮具备悬停高亮（PC）与按下缩放/变色反馈，点击播放统一 UI 音效；被置灰的按钮（MM-02）无悬停反馈、无点击音效。
- **验收**：鼠标悬停/按下有可见反馈；点击有可闻音效；置灰按钮完全无响应。

### MM-10 分辨率与布局适配（P0）
- **需求**：以 1920×1080 为基准分辨率，Canvas Scaler 按屏幕高度适配；16:9 ~ 21:9 范围内按钮组不越界、不重叠；Android 端避让刘海/圆角安全区。
- **验收**：1920×1080、2560×1080、2340×1080（手机竖屏横用场景不测）三种分辨率下全部按钮完整可点，文字不裁切。

## 5. 非功能需求

- 从点击游戏图标到主菜单可交互 ≤ 3 秒（PC 打包版，不含平台启动器）。
- 主菜单静止状态帧率 ≥ 60 FPS（PC）。
- 所有中文文本使用 TMP + NotoSansSC，无方块字/缺字。

## 6. 边界与异常

| 情况 | 期望行为 |
|---|---|
| 存档文件损坏 | 按"无存档"处理（继续游戏置灰），不弹错误框；细节见 05 篇 SV-03 |
| 玩家连点按钮 | 场景切换/面板打开期间屏蔽重复点击，防连点触发两次切换 |
| 设置面板/成就面板已打开时再点其他菜单按钮 | 面板模态化：先关面板才能操作底层按钮 |

## 7. 依赖

- `GameBootstrap`（启动流程，已有）、UIModule（面板管理）、SceneModule（场景切换）、AudioModule（BGM 与音效）。
- 存档系统：MM-02/MM-03 依赖存档存在性与进度数据（05 篇）。
- 成就系统：MM-05 依赖 04 篇的成就列表界面。
