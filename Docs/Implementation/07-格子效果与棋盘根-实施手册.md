## 0. 执行纪律（先读，违反会浪费大量轮次）

### 0.1 通用约束

| 项 | 要求 |
|---|---|
| 命名空间 | 全部新增类保持 `Game.Board`，与现有棋盘代码一致（不要另起 `Game.Board.Effects`） |
| 目录 | 效果相关脚本放 `Assets/Scripts/Board/Effect/`（新建子目录）；效果资产放 `Assets/Data/Board/Effects/`（新建） |
| 改文件时机 | **写任何 `.cs` / `.unity` / `.prefab` 前先 `unity_editor.get_state`**，处于 Play 就先停并告知用户 |
| 编译 | 每步结束调用一次 `unity_editor.refresh`，**Console 0 error 才能进入下一步** |
| 保存 | 改过场景/预制体后用 `EditorSceneManager.SaveScene` / `EditorUtility.SetDirty` + `AssetDatabase.SaveAssets` |
| git | 所有 git 命令前加 `export PATH=/opt/homebrew/bin:$PATH`（git-lfs 依赖） |
| 并发写入 | 本项目存在并发改动：**每步开始先 `git status` 复核自己上一步的改动还在**，被还原就停下来问用户，不要静默重做 |
| 桥接脚本 | `exec_editor_script` 的编译上下文**没有 `UNITY_EDITOR` 宏**，不要调用标了 `[Conditional("UNITY_EDITOR")]` 的方法 |
| 枚举 | 新增枚举底层类型必须是 `int`（写 `long` 会让字段根本存不进场景） |
| `Object` 歧义 | 脚本里同时有 `using System` 时，`Object.FindObjectOfType` 会 CS0104；一律写 `UnityEngine.Object.` 或 `using Object = UnityEngine.Object;` |
| 取 Model | 外部取模型用 `BoardContext.Instance.GetModel<T>()`（已确认存在，见 `BoardRuntimeDriver`）；组件内部用 `this.GetModel<T>()` |

### 0.2 必须遵守的三条架构红线

1. **运行时状态不许写进 ScriptableObject。** `TileEffect` 资产全局共享，跨格、跨关、跨 Play 会话污染，且退出 Play 不还原。
   一切运行期状态（传送门已消耗等）存在 `BoardRoot` 的状态表里。
2. **效果不许直接操作 AI 或棋盘。** 效果只填 `TileEffectResult`，由 `BoardRunModel` 统一应用。
   发现自己在效果里调 `Model` 的 setter 或直接改 `aiCell.Value`，说明设计跑偏了。
3. **效果不许持有格子引用。** 跨格查询一律走 `ctx.Board` 的 `IBoardQuery` 方法。

## S1 · 效果基类与执行契约

**目标**：RE-02。建立多态体系与「效果只填结果」的契约。
**依赖**：无。**改完不破坏任何现有行为**（本步不加调用点）。

**`Assets/Scripts/Board/Effect/TileEffect.cs`**

using UnityEngine;

namespace Game.Board
{
    /// <summary>效果对外的唯一契约：AI 踏入时触发一次。</summary>
    public interface ITileEffect
    {
        string DisplayName { get; }
        Sprite Icon { get; }

**`Assets/Scripts/Board/Effect/TileEffectContext.cs`**

```csharp
using UnityEngine;

namespace Game.Board
{
    /// <summary>AI 的只读快照：效果据此判断，但不能改它。</summary>
    public struct AiPawnState
    {
        public Vector2Int Cell;
        public Vector2Int PreviousCell;   // 来路格（可能等于 Cell，表示「无来路」）
        public MoveDirection? LastDirection;
        public int StepCount;
    }

    /// <summary>效果执行后回填的结果；由 BoardRunModel 统一应用。</summary>
    public sealed class TileEffectResult
    {
        public Vector2Int? TeleportTo;
        public MoveDirection? ForcedNext;
        public bool ClearIncoming;
        public bool Stop;

        public bool HasAny => TeleportTo.HasValue || ForcedNext.HasValue || ClearIncoming || Stop;

        public void Clear()
        {
            TeleportTo = null; ForcedNext = null; ClearIncoming = false; Stop = false;
        }
    }

    /// <summary>传给效果的上下文：棋盘根是跨格联动的唯一入口。</summary>
    public readonly struct TileEffectContext
    {
        public readonly BoardRoot Board;
        public readonly Vector2Int Cell;
        public readonly AiPawnState Pawn;
        public readonly TileEffectResult Result;

        public TileEffectContext(BoardRoot board, Vector2Int cell, AiPawnState pawn, TileEffectResult result)
        {
            Board = board; Cell = cell; Pawn = pawn; Result = result;
        }
    }
}
```

## S2 · 棋盘根 BoardRoot

**目标**：RE-03、RE-04。整盘运行时聚合 + 跨格查询唯一入口。

### 新建文件

**`Assets/Scripts/Board/BoardRoot.cs`**

```csharp
using System.Collections.Generic;
using UnityEngine;
using Runestone.AesirArchitecture;

namespace Game.Board
{
    /// <summary>
    /// 棋盘根：整盘运行时数据的聚合节点，也是效果做跨格联动的唯一查询入口。
    /// 挂在 BoardGridView 同物体上。Refresh() 全量重建；运行期每步只走 MarkConsumed / SetEffectState。
    /// 继承 MonoViewController&lt;BoardContext&gt; 才能用 this.GetModel&lt;T&gt;()（项目惯例，见 BoardGridView）。
    /// </summary>
    public sealed class BoardRoot : MonoViewController<BoardContext>
    {
        public struct CellRuntime
        {
            public Vector2Int coord;
            public TileType type;
            public TileEffect effect;
            public bool consumed;
            public BoardTile view;
        }

        [SerializeField, Tooltip("为空时自动取同物体上的 BoardGridView")]
        BoardGridView gridView;

        BoardModel _board;
        CellRuntime[] _cells;
        int _width, _height;

        /// <summary>场景内单例：BoardRunModel 结算效果时从这里取（见 S4）。</summary>
        public static BoardRoot Instance { get; private set; }

        public int Width => _width;
        public int Height => _height;
        public bool IsReady => _cells != null && _cells.Length == _width * _height && _width > 0;

        // ---------- 生命周期 ----------
        void Start()
        {
            Instance = this;                      // ⚠️ 不要在 Awake 里赋值：MonoViewController 有自己的生命周期钩子
            _board = this.GetModel<BoardModel>();
            Refresh();

            if (_board != null)
            {
                _board.BoardCovered.AddListener(Refresh)
                    .RemoveListenerWhenGameObjectOnDestroyed(gameObject);
                _board.BoardResized.AddListener(Refresh)
                    .RemoveListenerWhenGameObjectOnDestroyed(gameObject);
            }
        }

        /// <summary>全量重建：从 BoardModel 拉数据 + 从 BoardTile 拉关卡预置效果（见下方实现要点）。</summary>
        public void Refresh() { /* 见下方实现要点 */ }

        /// <summary>清空全部效果运行期状态（重开时调用）；转发到数据层。</summary>
        public void ResetEffectStates() => _board?.ResetEffectStates();

        // ---------- IBoardQuery（效果只能用这些） ----------
        public bool InBounds(Vector2Int cell);
        public TileType TypeAt(Vector2Int cell);
        public TileEffect EffectAt(Vector2Int cell);
        public bool IsConsumed(Vector2Int cell);
        public void Consume(Vector2Int cell);
        public bool TryFindNearestPortal(Vector2Int from, out Vector2Int target);
        public List<Vector2Int> CellsWithEffect();
        public Vector3 CellToWorld(Vector2Int cell);
        public BoardTile ViewAt(Vector2Int cell);
    }
}
```

`Refresh()` 实现要点：

1. `gridView` 为空则 `GetComponent<BoardGridView>()`；拿不到就 return。
2. `_width = gridView.Width`、`_height = gridView.Height`；`_cells = new CellRuntime[_width * _height]`。
3. 逐格填：
   - `type = _board != null ? _board.TypeAt(coord) : tile.PresetType`
   - `effect = _board != null ? _board.EffectAt(coord) : null`
   - **回落**：`effect == null` 时取 `view.PresetEffect`（关卡预置）
   - **钉死**：`view != null && view.PinEffect` 时**强制**用 `view.PresetEffect`，忽略 BoardModel 的值
   - `consumed = _board != null && _board.IsEffectConsumed(coord)`（**从数据层读，不在这里维护**——见 S3）
4. `view` 取 `gridView.TileAt(coord)`（S7 在 `BoardGridView` 上补这个方法）。
5. **不重置 consumed**——一次落盘不该让传送门复活；只有 `ResetEffectStates()` 才清。

> `consumed` 之所以放 `BoardModel` 而不是 `BoardRoot`：全盘扫描（传送门找最近）需要在数据层遍历，
> 且 `BoardRunModel` 是纯 Model，只能通过 `GetModel<BoardModel>()` 拿数据。`BoardRoot` 的 `Consume` /
> `IsConsumed` 只是转发。

## S3 · 两层数据模型落到 BoardModel

**目标**：RE-01、RE-07。给 `BoardModel` 加与 `_tiles[]` 平行的效果数组。

### 修改 `Assets/Scripts/Board/BoardModel.cs`

新增字段与方法（**不要动现有 `TryCover` 之外的逻辑**）：

```csharp
TileEffect[] _effects;        // 与 _tiles 平行，行主序
TileEffect[] _presetEffects;  // 关卡预置快照，供 RestorePreset 还原
bool[] _consumed;             // 效果运行期状态（传送门已用）；同样与 _tiles 平行

public TileEffect EffectAt(Vector2Int cell) =>
    InBounds(cell) && _effects != null ? _effects[Index(cell)] : null;

/// <summary>调试/关卡预置写入口（S7 画笔会用到）。</summary>
public void SetEffect(Vector2Int cell, TileEffect effect)
{
    if (!InBounds(cell)) return;
    if (_effects == null || _effects.Length != width * height) _effects = new TileEffect[width * height];
    _effects[Index(cell)] = effect;
    BoardCovered.Invoke();     // 复用现有事件驱动 BoardRoot.Refresh 与视图刷新
}

// ---- 效果运行期状态（只在这里存，绝不写进 TileEffect 资产）----
public bool IsEffectConsumed(Vector2Int cell) =>
    InBounds(cell) && _consumed != null && _consumed[Index(cell)];

public void ConsumeEffect(Vector2Int cell)
{
    if (!InBounds(cell)) return;
    if (_consumed == null || _consumed.Length != width * height) _consumed = new bool[width * height];
    _consumed[Index(cell)] = true;
}

public void ResetEffectStates()
{
    if (_consumed == null || _consumed.Length != width * height) _consumed = new bool[width * height];
    else System.Array.Clear(_consumed, 0, _consumed.Length);
}
```

改动点：

1. `Reset()`：同时 `_effects = new TileEffect[width * height]`。
2. `RestorePreset()`：`_effects` 用 `_presetEffects` 还原（没有则清空），并调 `ResetEffectStates()`。
3. `ApplyPreset`：新增**重载**接收效果（`CellPreset` 结构或直接 `IEnumerable<KeyValuePair<Vector2Int, TileEffect>>`），写入 `_effects` 并克隆进 `_presetEffects`；**保留**旧的只收 `TileType` 的重载。
4. `TryCover(anchor, TilePiece)`：逐格写 `_effects[index] = piece.EffectAt(i)`。
5. `TryCover(anchor, shape)` / `(anchor, shape, fill)` 两个旧重载：把覆盖到的格子的 `_effects` 置 `null`（不带效果的方块会清掉预置效果——RE-07 默认语义）。

### 修改 `Assets/Scripts/Board/TilePiece.cs`

加一条与 `_cellTypes` 平行的 `TileEffect[] _cellEffects` + `EffectAt(int index)`，构造签名扩为
`TilePiece(TileShape shape, TileType[] cellTypes, TileEffect[] cellEffects = null)`（**默认参数保证 S3 单独编译通过**，S9 才真正传值）。

## S4 · 效果触发链路（改 Step）

**目标**：RE-08、RE-12。这是**唯一改动核心规则**的一步，务必先跑通回归再继续。

### 修改 `Assets/Scripts/Board/BoardRunModel.cs`

新增字段：

`Step()` 改造（保持原有语义，只在移动后插入效果结算）：

```csharp
public void Step()
{
    if (!IsRunning || _board == null || _preference == null) return;

    var from = aiCell.Value;

    // 1) 强制方向优先，且强制方向下不查掉头禁令
    if (_forcedDirection.HasValue)
    {
        var dir = _forcedDirection.Value;
        _forcedDirection = null;
        var forced = from + MoveDirectionInfo.Offset(dir);
        if (!CanEnter(forced)) { Finish(RunResult.Lose); return; }
        MoveTo(forced, dir);
        if (SettleAfterMove(forced)) return;
        return;
    }

    // 2) 原逻辑：按偏好顺序，排除来路格
    var order = _preference.Order;
    for (var i = 0; i < order.Count; i++) { /* 同原实现，命中后调 MoveTo + SettleAfterMove */ }
    Finish(RunResult.Lose);
}

/// <summary>移动 + 计数 + 事件（把原 Step 里重复的三行收进来）。</summary>
void MoveTo(Vector2Int target, MoveDirection dir)
{
    _previousCell = aiCell.Value;
    _lastDirection = dir;
    aiCell.Value = target;
    stepCount.Value += 1;
    AiMoved.Invoke();
}

/// <summary>移动后：终点判胜 → 结算效果。返回 true 表示本步已结束。</summary>
bool SettleAfterMove(Vector2Int target)
{
    if (target == _board.GoalCell) { Finish(RunResult.Win); return true; }

    var root = Root;
    if (root == null) return false;

    var effect = root.EffectAt(target);
    if (effect == null || root.IsConsumed(target)) return false;

    _effectResult.Clear();
    var ctx = new TileEffectContext(root, target,
        new AiPawnState { Cell = target, PreviousCell = _previousCell,
                          LastDirection = _lastDirection, StepCount = stepCount.Value },
        _effectResult);

    try { effect.OnEnter(ctx); }
    catch (System.Exception e) { Debug.LogError($"[BoardRunModel] 效果 {effect.DisplayName} 执行异常：{e.Message}"); return false; }

    ApplyEffectResult(target);
    return false;
}

void ApplyEffectResult(Vector2Int from)
{
    var r = _effectResult;

    if (r.TeleportTo.HasValue)
    {
        var dest = r.TeleportTo.Value;
        if (_board.InBounds(dest))
        {
            aiCell.Value = dest;                 // 传送不计入 stepCount（待定项 A）
            _previousCell = dest;                // 清空来路：来路=自身即「无来路」
            AiMoved.Invoke();
            if (dest == _board.GoalCell) { Finish(RunResult.Win); return; }
        }
    }

    if (r.ForcedNext.HasValue) _forcedDirection = r.ForcedNext.Value;
    if (r.Stop) { Finish(RunResult.Lose); return; }
}
```

同时：

- `ResetRun()` / `Play()` 里 `_forcedDirection = null;`（防跨局残留）。
- 效果消耗状态无需在此处理——`BoardModel.RestorePreset()` 内部已调 `ResetEffectStates()`（S3 改动点 2），`RestartLevel` 走它即可。
- `BoardRoot.Consume(cell)` / `IsConsumed(cell)` 是 `BoardModel.ConsumeEffect` / `IsEffectConsumed` 的转发，效果里调 `ctx.Board.Consume(...)` 实际写在数据层。

## S6 · 传送门效果

**目标**：RE-10、RE-11。

### 新建 `Assets/Scripts/Board/Effect/PortalEffect.cs`

```csharp
using UnityEngine;

namespace Game.Board
{
    [CreateAssetMenu(menuName = "Game/棋盘/效果/传送门", fileName = "Portal")]
    public sealed class PortalEffect : TileEffect
    {
        // 无参数：全场共用一个资产。状态（已消耗）存在 BoardModel 的数据层，不存这里。
        public override void OnEnter(TileEffectContext ctx)
        {
            if (!ctx.Board.TryFindNearestPortal(ctx.Cell, out var target)) return;  // 无配对 = 普通路格
            ctx.Result.TeleportTo = target;
            ctx.Result.ClearIncoming = true;
            ctx.Board.Consume(ctx.Cell);      // 入口失效
            ctx.Board.Consume(target);        // 出口同时失效
        }
    }
}
```

### `BoardRoot.TryFindNearestPortal` 实现要点

```
候选 = 全盘所有格子 c，满足：
  c != from
  EffectAt(c) is PortalEffect
  !IsConsumed(c)
按 (曼哈顿距离 |dx|+|dy|, y, x) 升序取第一个
候选为空 → 返回 false
```

### 建资产

`Assets/Data/Board/Effects/Portal.asset`，`displayName` = 「传送门」。

### 验收（确定性）

沿用 S5 的骨架（`ctx / board / run / shape` 同样取法），把铺路与效果换成下面这段，Step 循环照抄：

```csharp
var portal = /* 取 Assets/Data/Board/Effects/Portal.asset，取法同 S5 */;
var root   = Game.Board.BoardRoot.Instance;

for (int x = 1; x <= 9; x++) board.TryCover(new Vector2Int(x, 0), shape);  // 底行铺通
board.TryCover(new Vector2Int(2, 7), shape);                               // 落点单独铺一格
board.SetEffect(new Vector2Int(5, 0), portal);
board.SetEffect(new Vector2Int(2, 7), portal);

run.CompleteBuilding();
run.Play();
/* …Step 循环与 trace 打印同 S5… */

Debug.Log($"consumed_50={root.IsConsumed(new Vector2Int(5,0))} consumed_27={root.IsConsumed(new Vector2Int(2,7))}");
```

**判据（逐条）**：

1. 轨迹里出现 `… → (5,0) → (2,7)`（传送发生，落点不回传）。
2. 传送后 `run` 的来路为空——AI 可朝任意方向（含回 (5,0) 的方向）走。
3. 传送后 `root.IsConsumed((5,0))` 与 `root.IsConsumed((2,7))` 均为 `True`。
4. **退出 Play 再进**，两个门重新可用（证明状态没写进 SO）。
5. 只放**一个**门时：踩过去等于普通路格，AI 继续正常行走，不传送、不判负。
