## 逐款分析

### 1. Shotgun King: The Final Checkmate（PUNKCAKE Delicieux, 2022）
![截图](images/Shotgun_King_The_Final_Checkmate_1.jpg)

- **风格**：复古街机像素 + CRT 模拟（水平扫描线、暗角、边缘红蓝色差）。注意文字、棋盘、UI **全部吃同一层滤镜**，否则会有贴图感。
- **色彩**：调色板克制（约 8–12 色）。背景深蓝近黑，棋盘奶油白×淡薰衣草紫；只有品红/亮粉作为高亮信号色（HP、楼层数）。
- **棋盘**：8×8 标准格，浅色格角上点了"针脚"式小白点、底边有缝线状虚线装饰——微装饰注入手工/诡异质感。
- **棋子**：黑描边 + 白填充的标准棋形像素剪影，靠外轮廓识别（小尺寸下**轮廓 > 内部细节**）。招牌技法：给标准棋子加一处破坏性细节（国王身上插剑）做叙事性静帧。
- **UI**：淡蓝灰细线框 HUD，左右两侧用**空心方框占位**表示未解锁装备/灵魂槽——比画满图标更干净，还暗示成长空间。

### 2. Pawnbarian（j4nw, 2021）
![截图](images/Pawnbarian_1.jpg)

- **风格**：扁平矢量插画，但轮廓保留手绘的微抖动感；纯色块 + 统一粗描边 + 极少阴影。气质像暗色调奇幻桌游说明书。
- **色彩即信息**：深靛蓝大底，珊瑚红 = 敌方/污染/危险，白 = 玩家，黄/橙金 = 资源能量。红与白在蓝底上形成阵营对立，一眼分敌我。
- **棋盘**：约 6×5 小棋盘。**被污染的格子用半透明品红色相偏移**表示；**格子四角用红色爪痕角标（corner glyph）标记攻击范围**，而不是整格涂满——传达机制信息又不破坏棋盘整洁。
- **棋子**：棋形剪影 + 怪诞脸谱混搭——玩家是白色标准棋形，敌方把棋子"头"换成夸张的独眼哥布林/獠牙兽面。选中态 = 白色光晕圈。
- **UI**：图鉴式排版：衬线 small-caps 标题、斜体 flavor text、关键词用红色呼应棋盘污染色；状态用极简小图标（红 X / 灰盾 / 黄闪电）表达，不靠文字。

### 3. The Ouroboros King（Oriol Cosp Games, 2023）
![截图](images/The_Ouroboros_King_1.jpg)

- **风格**：扁平矢量 + 单色剪影图标，叠加纹章学/中世纪手稿气质。无渐变、无投影、无噪点。
- **色彩**：低饱和冷双色调（蓝灰 + 浅灰紫/米白），**全屏唯一强调色是红**，且只用于交互反馈（选中描边、可走格红点）。背景径向渐变暗角聚光棋盘。
- **棋盘**：8×8 俯视，**刻意压低格子对比度**（蓝灰×淡紫灰而非黑白），让棋盘"退后"不抢棋子。四周细浅外框像裱框。
- **棋子**：核心技法是**反色描边**——白方 = 白填充 + 黑描边，黑方 = 黑填充 + 白描边；无论落在深格浅格轮廓都清晰。这是解决"图标在双色底上都要可读"的通用答案。
- **UI**：白色单色线条图标系统（齿轮/戴冠骷髅/卷轴/钱袋），古典衬线字体 + 老式数字字形营造年代感；一行斜体 flavor text 做低成本"安静叙事"。

### 4. King of the Bridge（Finn Schuuring, 2024）
![截图](images/King_of_the_Bridge_1.jpg)

- **风格**：像素骨架 + 手绘灵魂的混合——可见像素网格，但轮廓粗黑、圆润、故意歪斜，像马克笔随手勾的草图。
- **色彩**：低饱和复古色板：深墨绿底 + 奶油米黄棋盘/书页（做旧纸张感），唯一点缀色是橙红（强调文字）。背景叠低对比波浪线/圆点纹理层。
- **棋盘**：装饰镶嵌格——浅格纯米黄，深格做"绿底 + 内嵌浅色方框"的画框效果，整盘棋像拼布/马赛克；边框四角带像素星形徽记，营造"织物上的棋盘"物件感。
- **棋子**：拟人化剪影小角色，圆头水滴兵、眯眼笑脸王、头顶飘 "Zzz" 的睡觉棋子——**用表情符号代替文字说明状态**。
- **UI 叙事化（最大亮点）**：规则说明做成一本摊开的怪诞手绘规则手册——米黄纸张、波浪书页轮廓、书脊折痕、像素手写体标题、简笔画图解走法。教程本身成为风格与幽默的载体。

### 5. Chessplosion（C.T. Matthews, 2021）
![截图](images/Chessplosion_1.jpg)

- **风格分层**：**像素前景 + 扁平矢量背景**混搭。战斗区全是硬边像素；背景是平滑橙色渐变 + 半透明低对比棋子剪影平铺——背景负责氛围不抢视线。
- **色彩语义**：暖橙背景 vs 冷灰棋盘形成温度对冲；酒红 + 金黄双线描边营造"皇家棋盘"仪式感。红 = 敌方/伤害，白 = 己方，黑 = 空洞陷阱，金 = 强调边框。
- **棋盘**：做成**带厚度的实体画框**（厚重暗红外框 + 金黄描边 + 外投影），浮在背景上。格子**用纹理区分功能**：普通格 / 人字形箭头纹（单向移动）/ 纯黑空洞（陷阱）——让棋盘自解释。
- **棋子**：符号拟怪化（红冠敌人、白棋主角），都带椭圆阴影底座；威胁弹丸是**带 bloom 发光的红色像素块**，与无光棋子对比自然引导视线；位移用**残影/拖影**表现，比逐帧动画省资源。
