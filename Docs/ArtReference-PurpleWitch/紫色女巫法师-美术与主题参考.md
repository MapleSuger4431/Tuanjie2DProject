| 山地 Mountain（不可覆盖） | `#150B22` | 0.51 | 1.05 : 1 | 故意压到最暗 + **描边 + 45° 斜纹 + ✕** |
| 起点 Start | `#F5EDFF` | 87.2 | 15.85 : 1 | 全场最亮（近白），配 ▶ 双圈 |
| 终点 End | `#FFC94D` | 63.6 | 11.79 : 1 | 鎏金，配 ★ / 传送门环 |

### 1.3 四条硬约束

1. **明度严格单调**：`Mountain 0.51 < Land 13.2 < Ice 33.2 < Fire 39.8`。转灰度后四态仍可分辨才算通过——**这是验收标准，颜色只是加成**。
2. **Ice ↔ Fire 亮度比仅 1.17**，必须靠色相（青 vs 橙）+ 图案（冰 = 六角晶纹，火 = 三角火苗纹）区分。青/橙是黄蓝轴对立，红绿色盲下最安全的一对。
3. **Mountain 与底色几乎同亮度**，只能用形状（描边 + 斜纹 + ✕）表达「不可通行」，不能用颜色。
4. **起点/终点务必加形状标记**：Start 与 Ice 亮度比 2.41、End 与 Fire 仅 1.53，只靠颜色会混。

> 若要更保守，终点可改为 `#B8FFEA`（薄荷白 + 呼吸光环），彻底避开金/橙混淆。

## 五、紫色在游戏里的语义与搭配规律

### 5.1 四类语义

1. **魔法 / 超自然** —— 原神雷元素、贝优妮塔魔导、Sword & Sworcery 的月亮与女巫
2. **异界 / 异质 / 非人** —— Obduction、Returnal、Rez、DELTARUNE 暗世界
3. **虚空 / 腐蚀 / 危险** —— Hollow Knight 的虚空、Terraria 腐化地
4. **稀有 / 高贵** —— Hades 的紫金、纪念碑谷的薰衣草粉紫

> 女巫/法师题材天然占「神秘 + 高阶」双关，是最省力的主色，但也最容易撞车。

### 5.2 搭配色

| 搭配 | 代表 | 气质 | 注意 |
|---|---|---|---|
| 紫 + 金 | Hades、艾尔登法环、Sayonara | 最高级、最「神性」 | 金只占 5–10% 做描边与高光 |
| 紫 + 粉/品红 | Monument Valley 2、Sable | 柔化、亲和，适合女性向 | 小心整体过「甜」 |
| 紫 + 橙/红 | Hotline Miami、Trine 元素分色 | 危险 / 敌我区分 | 紫作底、橙红作警示 |
| 紫 + 青/青绿 | Hyper Light Drifter、Solar Ash | 互补最强，「异界 + 生物光」 | ⚠️ 这是 2023–24 年 3A 被吐槽的「企业紫/紫青」公式，**独立 2D 想避开同质化应降低青的比例、换成金或粉** |

### 5.3 2D 项目最容易踩的坑

1. **高饱和紫大面积铺满必脏**：好用样本的紫饱和度都在 30–40%、明度偏高；暗紫要配「黑蓝 + 少量冷光」才高级（Hollow Knight、ANIMAL WELL）。
2. **紫 + 青双高饱和 = 撞色疲劳 + 色盲风险**：若紫是主色，敌我/可交互物要用**明度差 + 形状**再叠一层保险，别只靠色相。
3. **UI 文字可读性**：紫底放白字问题不大，但**红字或青字会糊**；推荐「深紫底 + 米白字 + 金描边」（Hades、DELTARUNE 都是这套）。
4. **紫色在移动端/低端屏色偏最严重**：紫是 sRGB 里最易因色域差异变「蓝」或变「灰」的色相，做手游务必在偏色屏验证主色阶。
5. **主色别只用一个紫**：成功案例都是**至少 4–5 档紫色阶**（暗底 / 中调 / 亮部 / 高光 / 阴影紫），不是单个紫加黑白。

### 品类规律

- **配色**：紫（魔法/夜）+ 墨绿（自然/采集）+ 暖橙（对冲冷的 cozy 感）是绝对主流。cozy 端走高饱和暖紫，硬核端走深紫黑 + 冷光，**选哪端直接决定受众**。
- **玩法套路频次**：熬药/调配 > 采集 + 图鉴（常绑扫帚飞行）> 开店/委托板 > 建造装修 > 卡牌（已从战斗外溢到社交、经济、叙事）> 变身/猫 > 双身份结构。
- **2D 表现**：手绘/绘本与像素各占一半。像素在内容量产速度上更安全，绘本在辨识度与宣传物料上更强。

## 十、落地：最小改动路径（尚未执行）

1. **零重绘**：5 张 PNG 不动画，Unity 侧用 tint 乘法着色映射到新色板（原图明度差还在，相对关系直接保留）。
2. **必须做**：Mountain 与 Void 光靠 tint 分不开（明度比 1.05）→ 单独加描边 + 45° 斜纹 + ✕，用形状表达「不可覆盖」。
3. **提质感**：Fire / Ice 现在是纯 `#F00000` / `#0090F0`，tint 成橙/青后补一层外发光，否则在紫底上显「贴纸感」。
4. **可选**：Aseprite 批量色相位移（Hue −30°、Sat −20%），保持 315×294 与 alpha 通道，导入设置不动，代码与预制体无需改动。
5. **验证**：改完转灰度截图 —— 四态灰度下仍能分辨才算通过。

> 一句话：先把 `Tile_Void` 与 `Tile_Mountain` 的明度拉开（这是当前真正的设计缺陷），其余靠 tint 就能完成 80% 换肤，不用重画。
