# 紫色 × 女巫 / 法师 视觉主题参考集

> 调研日期：2026-10-18。用途：给本项目棋盘玩法换「紫色魔法」主题时提供配色、主题包装与素材线索。
> 本目录**只做参考归档，不含可运行改动**；未修改任何 `Assets/` 贴图与代码。
> 配套先例：`../ArtReference-2DChess/`（2D 棋盘游戏美术风格，2026-10-17 调研，结论同样偏紫）。

## 结论先看（三条）

1. **主题不用「选」，只需要「统一」** —— 项目里已经有紫调女巫/法师角色：`Assets/Art/Character/Character_Portrait.png`（Q 版二头身少女，浅紫渐变粉紫长发、黑底斗篷带品红描边、领口紫水晶、脚下紫色魔法阵）。棋盘与 UI 应当向这张立绘的色板对齐，而不是另起一套。
2. **魔法语义的挂点已经现成** —— `Docs/Requirements/07-格子效果与棋盘根需求.md` 新增的效果层（传送门、强制转向）天然就是「魔法」，主题包装不需要额外造概念。
3. **当前素材有一个真实缺陷** —— `Tile_Mountain #181848` 与 `Tile_Void #001848` 明度几乎相同（对比 1.05:1），山地格光靠调色分不出来，必须靠形状标记解决。
